# Chr6 26M-27M
I applied internal-prior PolyFun[@weissbrod2020functionally] [SUSIE](../../../../../Bioinformatics_Concepts/SUSIE.md)[@wang2020simple] [fine-mapping](../../../../../Bioinformatics_Concepts/Fine_Mapping.md) to the first [DecodeME](../../../../../Data_Sources/DecodeME.md)[@genetics2025initial] GWAS-1 signal on Chromosome 6 using the same methodology as I used on the [Chromosome 1 locus](a_Polyfun_Chr1_173M_174M_Locus.md).  As was the case with my [uniform-prior](../SUSIE/b_Chr6_26M_27M_Locus.md) and [external-prior](../SUSIE-PolyFun_(External_Prior)/b_Polyfun_Chr6_26M-26M_Locus.md) analyses, this analysis failed to find any credible sets.  Given that this locus lies in the HLA region, notorious for its complex LD, this result is perhaps unsurprising.
